# 找片兜底策略

当固定搜索链没有找到**可核验**的目标影片，或只找到容量明显异常、失效、错片的候选时，读此文件再扩大搜索。站点提供线索，不代表文件真实画质、迅雷可离线或有权保存。每次新增策略应记录具体影片、原页、链接类型、文件大小和实测结果，不能把单次命中概括为整站可靠。

## 优先走的路线

1. **确认目标**：锁定中文名、英文原名、上映年份、别名、系列序号。系列合集要拆成单片核对；同名电影先用年份消歧。
2. **聚合搜索**：先用 [PanSou](https://github.com/fish2018/pansou) 和 `search_sources.py` 批量检索；本轮选入的部分分享来自其 PanSearch 插件。搜到分享链接后，读取真实分享文件清单；聚合页标题只是线索，某片返回 0 也不代表无资源。
3. **高产站点逐片搜索**：优先使用 SeedHub 永久入口 [https://sidhub.cc/](https://sidhub.cc/)，按 `https://sidhub.cc/s/片名/` 站内搜索；不要依赖 `seedhub.cc` 等可能失效的旧域名。进入电影页后选“迅雷”标签，再打开跳转页取得实际的迅雷分享链接及提取码。进入 4K 候选后按 `search-and-quality.md` 评分：4K、杜比、蓝光、MKV 四个类别叠加加分，优先 4K 高码率重编码版，视频码率目标 25–45 Mbps；常规片长单片略低于 30 GB，超过 150 分钟允许超过 30 GB，不再优先最大文件。核对实际文件名、年份、剪辑版、片长、视频格式和大小后再选；按 `search-and-quality.md` 的完整性闸口对比同版公开片长，缺碟/异常片长排除，时长未知只列待核验；合集总容量不能代替单片容量。其次查 [普鲁文 4K 磁力清单](https://pluwen.com/posts/awesome-4k-video-magnet-download)，核对磁力对应影片、容量和离线结果。本轮最终入盘的实例见下方“有效资源点”。
4. **通用搜索扩展**：中文名、英文名、年份分别搜索；组合 `4K`、`2160p`、`UHD`、`1080p`、`迅雷云盘`、`磁力`、`BT`、`thunder`，再加 `site:sidhub.cc` 等已命中站点。先找片页与文件清单，再找可用链接，不能只凭搜索摘要提交任务。

5. **浏览器人工式兜底**：脚本和网页搜索仍无可信候选时，按 [browser-fallback.md](browser-fallback.md) 打开搜索结果原页、站内搜索与跳转页，观察实际可见的分享链接、提取码、文件名及容量；允许模型根据页面结构换关键词。浏览器受限要如实记录，不称已穷尽。

## 候选筛选与排障

| 现象 | 下一步 |
|---|---|
| 聚合搜索返回 0 | 换英文名、别名、年份、系列内单片名；去高产站点站内检索，并搜索迅雷分享以外的磁力、种子、`thunder://`、HTTP/HTTPS/FTP 线索。 |
| 站点标“迅雷”却跳到别的网盘，或合集混片 | 打开实际落地页；读取 `pan.xunlei.com/s/` 分享真实清单，按文件 ID、年份、大小核对。不能按标签转存整包。 |
| SeedHub 的“雷神合集”实际分享《毒液》，或标称 4K 的合集含 1080p、RAR、蓝光原盘目录 | 逐文件核对真实分享内容与视频格式；不按电影页标题或合集标签整包转存。 |
| 分享显示失效、敏感资源或提取码错误 | 记下具体服务端状态，停止该链接；换站点、版本、分享者或磁力候选。不要反复提交同一失效链接。 |
| 标称 4K 但常规长片不足 10 GB | 降低画质置信度，查看片长、编码、码率或其他版本；10 GB 是用户偏好阈值，不是画质鉴定结论。可信 1080p 可作为兜底。 |
| 文件名为 `1.mkv` 等泛名 | 用分享目录、片页标题、年份、文件大小交叉核对；信息不足时保留“待核实”，不要从目录名直接认定正片。 |
| 磁力离线被版权限制或只得到 BDMV 原盘目录 | 换合法可用来源或可直接播放的 MKV/MP4 版本；本轮普鲁文《霍比特人：意外之旅》只得到 BDMV，《扎克版正义联盟》被迅雷拒绝，均未把该磁力算作成功。不能把任务创建或原盘目录当成 TV 正片可播放成功。 |
| 站点出现 Cloudflare 1015 等限流 | 停止访问该站，切换其他渠道，稍后再试；不要尝试绕过。 |
| 只有搜索摘要、网页声明、无法回查链接 | 报“待核实线索”；实际完成上述搜索仍无候选时，报“本次未找到可核验资源”并列出受限渠道。 |

比较时先确认**影片身份**，再看分辨率声明、容量和版本信息。默认优先可信的 2160p/4K，缺少时退到可信 1080p；`来源标称4K` 之类的声明不能变成实测结论。将用户后来教的有效站点与关键词策略补到本文件；只有最终选优入盘并读回的影片才追加到“有效资源点”，附一条可复查的实例。
