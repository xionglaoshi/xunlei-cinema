# 浏览器搜索兜底

脚本初搜和 Agent 网页搜索补查之后，若仍无可信 4K、候选疑似错片、只有搜索摘要，或无法比较质量，使用当前 Agent 可用的浏览器自动化工具补查。浏览器是最后的补漏和语义核验通道；可打开已找到的候选原页，不必重复所有查询。

## 检索步骤

1. 优先用 Google 搜索精确片名、上映年份和英文名，组合“迅雷云盘/迅雷下载/thunder:///磁力/种子/4K/2160p/1080p”等词；必要时再用百度或候选站内搜索。系列片逐部检索，避免整组结果互相串片。
2. 搜索摘要和搜索引擎 AI 概览只能提供线索，不能作为链接、容量或影片匹配的证据。打开候选原页核对影片名、年份、版本、链接附近说明、文件名、分辨率、容量和片长；列表或长帖中多个链接必须逐条匹配上下文，不能把页面标题直接套给所有链接。原页打不开或信息对不上时，降为“待核实”，不复述 AI 概览生成的磁力哈希或文件细节。
3. 把页面中展示的迅雷分享、`thunder://`、磁力、种子下载页或公开 FTP 记为“页面声称/列出”，并保留可回查来源页。只在可见文本里检查链接，不触发媒体、种子或压缩包下载。
4. 若页面需要登录、验证码、绕过访问限制或触发下载，停止该页面操作，记录受限原因，转查其他来源；不得尝试规避访问控制。

## 证据分级

- **搜索命中**：只有搜索结果标题或摘要。仅作线索，低置信度。
- **页面列出资源**：打开原页并看到目标影片及链接/资源声明。可确认页面在发布该线索，不能证明当前有效或内容真实。
- **链接可访问**：迅雷分享页面可打开，或链接语法可解析。只说明链接可访问/格式有效，不证明文件属于目标影片。
- **内容匹配**：已查看分享目录或种子元数据，文件名、年份、版本吻合。仍不能证明真实画面分辨率。

把“页面声明”“链接状态”“影片匹配”“画质真实性”分开报告。未实际读取的种子元数据、未打开的分享目录，以及仅出现在摘要中的容量一律写“未核实”。网页浏览器不下载媒体、不提交迅雷离线任务、不转存网盘。

结束浏览器补查后，若至少有一个目标影片的来源页或链接，按核验程度报告候选；所有结果均是错片、失效或无法回查时，才报告“本次未找到可核验的资源”。浏览器通道无法使用时注明该阶段未完成和原因，不把未查到等同于资源不存在。
